## 5. Phase 2A vs Phase 2B Discrepancy

### The 5,251 Count (Phase 2A)

The Phase 2A report mentioned approximately 5,251 vocabulary records. This number
comes from `data/seed/gen_sql.py`, which merges `vocab_enriched.json` (5,000) and
`vocab_fixed.json` (500):

```
merged = enriched (5,000) ∪ fixed (500)
       = 5,000 + 251 (fixed-only) = 5,251
```

- 4,751 words from enriched only
- 249 words in both (fixed overrides enriched)
- 251 words from fixed only
- **Total: 5,251**

### The 5,000 Count (Phase 2B)

The Phase 2B seed (`seed_vocab_cards.sql`) was generated by
`supabase/seeds/generate_seed.py`, which reads **only** `vocab_enriched.json`:

```
seed = vocab_enriched.json (5,000 records)
```

### Discrepancy Explanation

| Difference | Count | Reason |
|------------|-------|--------|
| Phase 2A (gen_sql.py) | 5,251 | Merges enriched + fixed |
| Phase 2B (generate_seed.py) | 5,000 | Uses enriched only |
| **Missing from Phase 2B** | **251** | `vocab_fixed.json`-only words not included |

The 251 words from `vocab_fixed.json` that are NOT in `vocab_enriched.json` are
absent from the current seed file. These are manually-curated entries that were
added to `vocab_fixed.json` but never merged into `vocab_enriched.json`.
