# Content Source Audit — EnglishApp

> Generated: 2026-09-01  
> Purpose: Identify original vs current content sources for all major datasets.

## Summary

The original EnglishApp content was stored in a SQLite database (`data.db`) committed at
the earliest git commit (`98321ac`). The database contained 50,017 vocabulary cards, but
only ~4,972 had fully curated content (real English + Vietnamese meanings). The remaining
~42,152 were auto-generated placeholder entries created by `data/seed/__init__.py` using
`wordfreq` word lists with placeholder text ("Common English vocabulary word: X").

During the web migration, the curated vocabulary was enriched (synonyms, antonyms, examples)
and stored in `data/seed/vocab_enriched.json` (5,000 words) and `web/public/data/vocab.json`
(5,251 words — enriched + fixed corrections). The Supabase seed SQL contains 5,000 words.

### Overlap Analysis

- **Common words** (original curated ∩ seed): 4,983
- **Words in seed but not original**: 17 (common words like "a", "i", "on", "be", etc.)
- **Words in original curated but not seed**: ~0 (seed is a superset)
- **Meaning differences**: 1,701 of 4,983 common words have different `meaning_en` — the
  current version has improved/expanded definitions from the enrichment process

### Assessment

The current web vocabulary (5,251 words) is the **correct production content**. It is an
enriched and corrected superset of the original curated vocabulary. The original SQLite's
50,017 entries were mostly low-quality auto-generated fillers that should NOT be restored.

**Action needed**: Sync the Supabase seed SQL to match the web JSON (add missing 251 words).

```

    ↓ writes to

    ↓ enriched by expand_vocab.py (Free Dictionary API, Datamuse, Google Translate)
data/seed/vocab_enriched.json (5,000 words, array synonyms/antonyms)
    ↓ merged with
data/seed/vocab_fixed.json (~100 manual corrections)
    ↓ generates SQL via gen_sql.py
web/supabase/migrations/002_seed_vocab.sql (5,251 words, legacy schema)
    ↓ generates SQL via supabase/seeds/generate_seed.py

    ↓ also copied to
web/public/data/vocab.json (5,251 words, frontend fallback)
```
